# H2O Alex — оплата, Telegram і редагування товарів

## 1. Редагування товарів в адмінці (вже працює)

1. У Firebase відкрийте **Firestore → Rules**, вставте новий `firestore.rules`, натисніть **Publish**
   (додано правило для товарів — без нього зміни не збережуться).
2. Опублікуйте оновлений сайт на Vercel (див. розділ «Оновлення сайту на Vercel» нижче).
3. Зайдіть на сайт як адмін → **⚙️ Адмін → 🛍️ Товари**.
4. Вперше натисніть **«Імпортувати 19 товарів»** — стандартні товари потраплять у базу.
5. Далі: ціну можна змінити прямо у списку, 👁️ — сховати/показати товар, ✏️ — повне редагування
   (назва, опис, категорія, емодзі або фото за посиланням, «Хіт»), «+ Додати товар» — новий товар.

Фото: завантажте картинку на будь-який сервіс (наприклад imgbb.com або Google Drive з публічним доступом)
і вставте пряме посилання `https://…` у поле «Фото».

## 2. Оплата

### Що вже є
У кошику клієнт обирає спосіб оплати:
- **Готівка кур'єру** та **Картка кур'єру** — працюють одразу, спосіб видно в адмінці.
- **Переказ на картку** — вмикається, коли ви впишете у `app.js`:
  ```js
  const PAY_CARD = "5375 41XX XXXX XXXX";
  const PAY_CARD_HOLDER = "Олександр К.";
  ```
  Після замовлення клієнт побачить вікно з номером картки, сумою та кнопкою «Скопіювати».
  Підтверджувати надходження коштів доведеться вручну: змінюєте статус замовлення в адмінці.

### Онлайн-оплата карткою на сайті (наступний крок)
Для цього потрібен договір еквайрингу (ФОП/ТОВ). Найпростіші варіанти в Україні:
**Monobank Acquiring**, **LiqPay**, **WayForPay**.

Як це працює технічно: сайт → ваша серверна функція (Vercel Function) створює рахунок у банку
→ клієнт переходить на сторінку оплати → банк надсилає підтвердження (webhook) → замовлення
автоматично отримує статус «Оплачено». Секретний ключ банку **не можна** класти в `app.js` —
він лежить тільки в налаштуваннях сервера.

Коли отримаєте доступ до еквайрингу (токен/merchant id), напишіть мені — я додам кнопку
«Оплатити карткою» під вибраний банк.

## 3. Сповіщення в Telegram про нові замовлення

Потрібно ~10 хвилин. Сайт сам токен не зберігає — для цього є невелика серверна функція на Vercel
(файл `api/notify.js` вже готовий, Vercel підхоплює папку `api` автоматично).

### Крок 1. Створіть бота
1. У Telegram відкрийте **@BotFather** → `/newbot` → вигадайте назву та ім'я (закінчується на `bot`).
2. BotFather дасть **токен** (виглядає як `123456:ABC-DEF...`). Збережіть його, нікому не показуйте.

### Крок 2. Дізнайтеся свій chat id
1. Знайдіть вашого нового бота в Telegram і натисніть **Start** (напишіть йому будь-що).
2. Відкрийте в браузері (підставте свій токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. У відповіді знайдіть `"chat":{"id":123456789` — це ваш **chat id**.
   (Для групи: додайте бота в групу, напишіть у ній повідомлення — id буде мінусовий, напр. `-100123…`.)

### Крок 3. Налаштуйте Vercel
1. Vercel → ваш проєкт → **Settings → Environment Variables**. Додайте три змінні (середовище: Production):
   - `TELEGRAM_BOT_TOKEN` — токен від BotFather
   - `TELEGRAM_CHAT_ID` — ваш chat id
   - `FIREBASE_API_KEY` — `apiKey` з вашого firebaseConfig (рядок `AIzaSy…`)
2. Опублікуйте сайт **разом з папкою `api`** (див. нижче). Після деплою у проєкті → **Functions** має
   з'явитися `api/notify`. Змінні набувають чинності тільки після нового деплою.

### Крок 4. Увімкніть у коді
У `app.js` змініть рядок:
```js
const NOTIFY_URL = "/api/notify";
```
і опублікуйте сайт ще раз.

### Перевірка
Зробіть тестове замовлення — у Telegram прийде повідомлення з клієнтом, телефоном, адресою,
товарами та сумою. Якщо ні: Vercel → проєкт → **Logs** (або Deployments → Functions) покаже помилку.

> Функцію я не міг перевірити з реальним ботом у своєму середовищі (немає доступу до Telegram),
> тому перший тест зробіть самі й напишіть мені, якщо щось не спрацює.

## 4. Оновлення сайту на Vercel

- **Через GitHub (рекомендовано):** замініть файли в репозиторії новими (зі збереженням структури: `index.html`,
  `style.css`, `app.js`, папки `assets` та `api`) → Vercel сам задеплоїть за хвилину.
- **Через термінал:** у папці сайту виконайте `vercel --prod`.
- Після кожної зміни змінних середовища потрібен новий деплой (Deployments → ⋯ → Redeploy).

### ⚠️ Не забудьте домен у Firebase
Адреса на Vercel інша, ніж була на Netlify (`щось.vercel.app`). Додайте її, інакше вхід через Google
покаже `auth/unauthorized-domain`:
**Firebase → Security → Authentication → Settings → Authorized domains → Add domain**
(без `https://`). Якщо підключите власний домен, додайте і його.

Також якщо відкриваєте посилання-превʼю (`…-git-…vercel.app`) — це інша адреса, її теж треба додавати.
Працюйте з головною адресою проєкту (Production).
